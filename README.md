# Smart_Travel_Planner
AI-powered travel planning web application built with JavaScript and Gemini AI API, featuring interactive map itineraries, custom CSS animations, and real-time tour progress tracking.


Smart Travel Planner – AI-Powered Web Application
Smart Travel Planner is a modern web application designed to help travelers discover refined destinations and generate AI-personalized itineraries through a premium user interface. Users enter their target city and natural language preferences, and the application dynamically builds an optimized route plotted directly onto an interactive map.   

Animated Landing Page: Features a dark/luxury travel aesthetic with a custom CSS flight-path and location-pin animation, alongside quick navigation for user login and account registration.   

User Authentication (Sign In): Dedicated login view with email and password authentication styled with travel-themed visuals.   

AI Travel Assistant (Gemini AI Integration): Interactive dashboard where users input a target city (e.g., Tokyo) and specific natural language prompts (e.g., student budget, underground culture, independent art galleries, local street food, second-hand vinyl shops) to automatically generate a tailored itinerary.   

Real-Time Interactive Mapping (Leaflet & OpenStreetMap): Automatically pans from the default view (Cluj-Napoca) to the selected city and plots interactive markers for each recommended attraction.   

Step-by-Step Tour Tracking ("Route in Progress"): Once the user confirms the itinerary, the app tracks real-time tour completion (0%, 33%, 67%, 100%), zooms into each stop sequentially, and displays detailed popup cards including attraction descriptions, location categories, estimated visit durations (e.g., 45 min, 20 min, 30 min), and distance indicators.   

Post-Tour Review System: Displays a completion screen at the end of the tour where users can rate their experience (1–5 stars) and submit written feedback.
